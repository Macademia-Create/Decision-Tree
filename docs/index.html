A decision tree, right in your workbook.

Build decisions, assign probabilities, compare expected values, find break-even points, and export the whole tree to PDF.

No Terminal. No Node.js.

Install once, then open Home → Macademia → Decision Trees in Excel. The hosted editor requires internet. Your workbook data stays in Excel.

Download Mac pilot package

Includes a readable installation helper, XML manifest and instructions. This is a pilot sideload, not a notarized macOS installer or Marketplace listing.

Install on your Mac

  1. Save your work and quit Excel. Download and unzip the package.
  2. Open Install Macademia.applescript in Script Editor and click its Run ▶ button. Confirm the installation dialog. It installs only this add-in for your Mac account and backs up older manifests for the same add-in.
  3. Reopen Excel. Choose Home → Add-ins → Macademia — Decision Trees to activate it the first time.
  4. Use the logo button under Home → Macademia → Decision Trees to open the editor. Choose New tree, or reopen an existing tree workbook.

If your organization blocks custom add-ins, ask its Microsoft 365 administrator to deploy the included XML manifest. The helper does not bypass organization settings.

Keep your work editable

Apply edits, then Save tree & workbook. Use .xlsx. On reopening, click the Macademia ribbon button to resume. PDFs and CSV files are not editable tree workbooks.
