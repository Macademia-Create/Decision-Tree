Install without the helper

This is Microsoft’s Mac sideloading procedure for a small pilot:

  1. Quit Excel and open Finder.
  2. Press Cmd + Shift + G and enter ~/Library/Containers/com.microsoft.Excel/Data/Documents.
  3. Create a folder named wef if it is missing.
  4. Copy Macademia.DecisionTrees.xml from the downloaded ZIP into that folder. Keep only one manifest with this add-in’s identity; the helper backs up old copies automatically.
  5. Restart Excel and select Home → Add-ins → Macademia — Decision Trees. Then use Home → Macademia → Decision Trees.

If it does not appear

Check that Excel has fully quit and restarted, that the XML file is in your account’s wef folder, and that you are using current Microsoft 365 Excel for Mac. A school or employer may disable sideloaded add-ins; ask its administrator to deploy the manifest instead.

If the editor does not load

Internet access is required. If the editor does not load, check that you are online and that your organization allows Office add-ins and GitHub Pages. Do not bypass browser certificate or security warnings.

Your existing MacDecisionTree workbooks

The add-in ID and workbook settings keys are unchanged, so your original tree metadata remains compatible. Load the original .xlsx file in Excel, then open Macademia. Do not keep both the old development manifest and the new hosted manifest active at the same time.

What the helper changes

The helper writes one XML manifest under your current user’s Excel wef folder. Older manifests with the same exact add-in ID are moved to a timestamped backup under ~/Library/Application Support/Macademia/Manifest Backups. It does not install system software, request administrator access, run Node.js or change your workbooks.

Remove the add-in

Quit Excel and move Macademia.DecisionTrees.xml out of the wef folder. Restart Excel. If Excel retains a cached entry, follow Microsoft’s Office add-in cache-clearing guidance. To return to the development build, restore its backed-up XML and restart your local development server.

Permissions and data

The add-in requests ReadWriteDocument so it can draw and edit tree worksheets and save their metadata. App code and icons are downloaded from this host, and Microsoft’s Office.js library is loaded from Microsoft. This release has no workbook-upload service, analytics SDK or external calculation API. Hosting and Microsoft may log normal web requests. PDF generation runs locally in the task pane.

Known pilot limits

Mac helper and ribbon activation still require a real Mac Excel installation test. The helper is a readable AppleScript, not a signed or notarized installer. PDF downloads may be blocked in some Excel web views; use the built-in Prepare Excel print fallback. Hosting is required for editor access, so keep an editable workbook backup.
